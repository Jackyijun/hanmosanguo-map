# 汉末三国形势图

黄巾起事至三国归晋（184—280）的交互历史地图，以东汉永元六年（94）的鼎盛疆域作序章。36 个时间节点的诸侯与政权疆域，313 个郡国城邑点的古今地名对照，117 场战役、50 个事件、27 处关隘、12 处都城行在，外加州界、蜀道栈道、曹魏孙吴运河三个时代专属图层。

---

## 一、直接看

双击 **`docs/index.html`**，用任意现代浏览器（Chrome、Edge、Safari、Firefox）打开即可。

这个文件约 1.4 MB，数据、样式、脚本全部内嵌：不联网、不需要服务器、不依赖任何外部库。

---

## 二、发布到 GitHub Pages

1. 把整个项目推到 GitHub 仓库（例如 `sanguo-map`）。
2. 在仓库的 **Settings → Pages** 里：
   - Source 选 **Deploy from a branch**；
   - Branch 选 **main**，目录选 **/docs**，保存。
3. 一两分钟后，网页就会出现在 `https://<你的用户名>.github.io/sanguo-map/`。

`docs/.nojekyll` 是一个空文件，作用是让 GitHub Pages 原样发布 `docs/` 里的文件，不经过 Jekyll 处理。

以后每次修改，运行 `python run.py`，把 `docs/index.html` 一起提交推送，网页就会自动更新。

## 三、本地重新构建

改了史料内容（`content/`）或参数（`src/config.py`）之后才需要重新构建。需要 **Python 3.9 或更新版本**。

**macOS / Linux**

```bash
cd sanguo-map
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py --open
```

**Windows（PowerShell）**

```powershell
cd sanguo-map
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run.py --open
```

完整构建约 30 秒，完成后会用浏览器打开新生成的 `docs/index.html`。

| 命令 | 作用 |
|---|---|
| `python run.py` | 检查底图 → 计算疆域 → 拼装 HTML |
| `python run.py --html` | 只重新拼装 HTML（只改了 `src/template.html` 时用，不到 1 秒） |
| `python run.py --open` | 构建完后在浏览器中打开 |
| `python run.py --preview 190,229` | 额外画出这几个节点的疆域草图到 `build/preview.png`，便于检查归属是否填错 |
| `python tools/preview.py 190 108,123,29,42` | 只画草图，可指定经纬范围（西,东,南,北） |

底图（`geodata/`，约 2 MB）已随项目附带，离线也能构建。如果删掉了 ETOPO20 地形文件，`run.py` 会自动从 GitHub 下载固定版本。

同一份输入，构建结果逐字节一致，可以用 git 追踪改动。

## 五、工作原理

```
content/*.py ─────┐
geodata/ (底图) ───┼─► build.py + terrain.py ─► build/*.json ─► assemble.py ─► docs/index.html
                  │                                               ▲
                  └───────────────────────────── src/template.html┘
```

### 1. 为什么疆域要“算”出来

汉末群雄没有现成的边界数据。史书能确定的大多是“某年某郡归某人”，而汉代郡界大体“随山川形便”。所以这里的做法是：

1. 只手写**郡国（城邑）→ 诸侯 → 政权**的归属及其变化年份（`nodes.py`）；
2. 用一张“通行代价”地图让计算机推出郡与郡之间的分界，让分界尽量落在山脊和大河上。

### 2. 疆域算法（`terrain.py`）

1. **海陆栅格**：经度 72°—136°、纬度 14°—55°，0.05° 一格（约 5 km），共 1280 × 820 格。大湖不可通行。
2. **代价栅格**：平地代价 1，再依次加上：
   - ETOPO20 算出的**地形起伏**（每 1300 米 / 度加 1，最多加 3.5），海拔 2700—3700 米再加最多 1（高原腹地难以控制）；
   - `base.json` 里的**山脉脊线**，沿脊线“烧”出一道高斯形高代价带，主干山脉峰值 +7、次要山脉 +3.5。手绘脊线是几段直线，先按固定种子加一点横向摆动；
   - **界河**：江 +3.5、河 +2.5、淮 +2、汉 +1.2；
   - 最后乘一层三尺度的平滑噪声（±42%），让界线带自然弯曲。
3. **多源最短路**：以全部 313 个点为源点，在 16 邻接网格图上跑一次 `scipy.sparse.csgraph.dijkstra(min_only=True)`，每格归“代价距离”最近的点。这是一种**加权 Voronoi**：边界被山脊、河道吸过去。16 邻接（含“马步”）比 8 邻接更接近各向同性，平原上的界线不会顺着格网走成横平竖直。
4. **无主地与外缘**：代价距离超过该点可达半径（`seeds.py` 里的 `R` × 1.45）的格子算无主地（漠北深处、青藏腹地）。各点的可达范围各是一圈等代价线，连起来会是一串圆弧，所以再对外缘做一次形态学闭运算（半径 0.7°）填平凹口、高斯平滑削掉小凸起。夹在疆域中间的小块空隙并回相邻疆域。
5. **界线曲折**：平原上两点之间的分界是一条直的中垂线，所以给整张归属栅格加一层平滑位移场，让所有界线都带上河曲一样的小弯。
6. **逐节点出多边形**：对每个节点，按“点 → 诸侯 × 州”合并格子，高斯平滑（σ = 1.25 格）后用 marching squares 描出 0.5 等值线。各块的等值线在两两相邻处本来就重合，只在三方交汇点留下小缝；把全部等值线打断成面、按所在块归属（缝里的面按栅格原归属），再用 GEOS 的**覆盖简化**（coverage simplify）整体简化。诸侯界、政权界、州界都由这同一批共享边合成，相邻两块之间是同一条线，不会有缝或叠压。
7. **注记点**：每个诸侯、政权、州取最大一块陆地的“不可达极点”（距离变换最大值处）。
8. **去重**：相邻节点里没变的疆域只存一份（`GEO.pool`），文件体积约减一半。

### 3. 前端（`src/template.html`）

骨架、色板、符号、交互全部按《历史形势图统一规范》，与唐宋、战国、隋唐三张图同一套：

- 零依赖：原生 JavaScript + SVG，Albers 等积圆锥投影（标准纬线 25°N、47°N，中心 108°E、34°N）。
- 着色可在“诸侯”（实际控制）与“政权”（名义所属）间切换；公孙氏、士燮、张鲁、黑山加斜线表示名义臣属、实则自立。
- 时代专属图层：州界（220 年前东汉十三州，三国按魏蜀吴各自的州，晋按太康十九州）、古道栈道（八条蜀道与卢龙道）、运河（按开凿年份出现）。
- 模板里有 4 个占位符：`__GEO__`、`__DATA__`、`__UCSS_LIGHT__`、`__UCSS_DARK__`，由 `assemble.py` 替换。

## 六、常见修改

**改某年某郡的归属**：在 `content/nodes.py` 对应节点的 `ops` 里加一项。每个节点继承上一节点的全部归属，只写变化的部分：

```python
("J", "南郡", "孙")        # 整个郡（含所属城邑）
("C", "柳城", "曹")        # 单个城邑或辅助点
("Z", "冀州", "曹")        # 整个州
("G", "乌桓", "鲜卑")      # 部族分区组
("ID", "黑山", "黑山")     # 以某前缀开头的所有点
("REPL", "孙", "晋")       # 整体替换
```

**新增一个城邑**：在 `content/seeds.py` 加一行 `C("名", "所属郡", 经度, 纬度, "今地", "按语")`，它会自动跟随所属郡的归属；需要单独易手时再在 `nodes.py` 里写。

**新增一场战役**：在 `content/items.py` 的 `BATTLES` 加一行（古名、今地、经纬度、年份、显示年代、胜负、主将、按语）。

改完运行 `python run.py --preview 年份` 看草图，确认无误再看网页。

## 七、调参

所有可调参数都在 `src/config.py`：

| 参数 | 作用 |
|---|---|
| `RES` | 栅格边长。改小更细，但计算更慢 |
| `RELIEF_SCALE` · `PLATEAU` | 地形起伏、高原海拔的代价 |
| `RANGE_PEAK` · `RANGE_WIDTH` · `RIDGE_*` | 山脊阻隔强度、宽度、摆动 |
| `RIVER_PEAK` | 界河代价 |
| `NOISE_*` · `WARP` | 界线弯曲的噪声与位移场 |
| `REACH_*` · `FRONTIER_*` · `MIN_WILD_CELLS` | 无主地范围、外缘平滑 |
| `SMOOTH_SIGMA` · `SIMPLIFY` | 轮廓平滑程度与简化容差 |
| `FIRST_YEAR` | 首屏节点 |

## 八、资料与可靠程度

- **疆域归属**：依据《后汉书》《三国志》《资治通鉴》《晋书》与谭其骧《中国历史地图集》第二、三册的大意推定，由 AI 协助编写，未逐条核对原文。大的格局和关键年份比较可靠；某郡某年的具体归属、边缘地区（西域、漠北、南中、辽东以东）的范围较粗略。
- **边界线**：完全是推算的示意线，只表示“这一带属于这一方”，不代表史书里有这样一条界线。
- **演义与正史**：《三国演义》的虚构情节（温酒斩华雄、三英战吕布、过五关、空城计、华容道义释等）不列为战役，只在相关条目按语里注明出入。
- **底图**：陆地、湖泊、河流、今国界来自 Natural Earth 1:10m（公有领域）；今省界与山脉脊线为手绘简化，沿用自《唐宋之际形势图》；地形为 NOAA ETOPO20（经 matplotlib/basemap 仓库分发）。
